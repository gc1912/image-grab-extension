# 电商图片提取下载（Chrome 扩展）

在淘宝、京东、拼多多（商家后台 + 买家详情页）的商品详情页一键提取图片，在新标签页中勾选并下载为 PNG。

## 安装

1. 打开 Chrome，访问 `chrome://extensions`
2. 打开右上角「开发者模式」
3. 点击「加载已解压的扩展程序」
4. 选择本项目文件夹 `image-grab-extension`

图标目前是纯色占位图，不影响功能，可稍后替换 `icons/icon16.png`、`icon48.png`、`icon128.png`。

## 使用

1. 打开支持的商品详情页：
   - 淘宝 / 天猫详情
   - 京东商品详情
   - 拼多多商家后台 `mms.pinduoduo.com` 商品相关页
   - 拼多多买家详情 `yangkeduo.com` / `mobile.yangkeduo.com`
2. 页面右下角出现「获取图片」按钮后点击
3. 在新打开的预览页中全选、反选或单独勾选
4. 点击「下载选中」，图片会转为 PNG，文件名形如 `商品图_001.png`，保存到浏览器默认下载目录

## 说明

- 仅在识别为详情页的地址显示按钮，首页、搜索页不会出现
- 已渲染且宽或高小于 100 的图会被过滤；尚未渲染（`naturalWidth=0`）的懒加载图会先保留
- 跨域原图依赖扩展声明的图片 CDN 权限进行转换；个别防盗链图片可能下载失败，其余会继续
